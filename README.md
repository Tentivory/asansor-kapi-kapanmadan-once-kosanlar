# Asansör Kapı Kapanmadan Önce Koşanlar Enstitüsü

Bu depo bir şakadır. Ama çalışır. İkisi aynı anda mümkün, tıpkı asansörün hem gelmesi hem gelmemesi gibi.

## Misyon

Kapı kapanırken “bir saniye!” diye koridorda sprint atan vatandaşı tespit eder, nezaket puanı keser, sonra da kapıyı zaten açar. Çünkü enstitü acımasızdır ama asansör müzikal değildir.

Kurum 1974’te hayali bir genelgede kurulmuştur. Genelge kayıptır. Kaybın tutanağı da kayıptır. Elimizde sadece bu Python dosyası var.

## Ne yapar

- Kaçıncı kattan bağırdığını sorar.
- Kapıya kaç metre kala koşmaya başladığını sorar.
- “Tutun!” diye bağırdıysan ekstra suç yazar.
- Düğmeye ikinci kez bastıysan dosyayı ağırlaştırır. Asansör bunu hissetmez. Sen hissedersin.
- Sonunda resmi bir karar çıkarır: biner, binmez, ya da merdivenle barışırsın.

## Kurulum

```bash
python3 kapi_mahkemesi.py
```

Bağımlılık yoktur. Vicdan opsiyoneldir.

```
DOSYA NO: AK-2026-13

```
